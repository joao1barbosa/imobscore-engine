# Architecture Decision Records

Registros de decisões de arquitetura que precisam de contexto e alternativas. Escolhas pontuais cabem em uma linha de `docs/decisions.md`.

## Como registrar

Crie `docs/adrs/NNNN-titulo-curto.md`, numerando em sequência a partir de `0001`, com estas partes:

```markdown
# NNNN · Título
Data: AAAA-MM-DD   Status: proposta | aceita | substituída por NNNN
## Contexto
## Decisão
## Alternativas consideradas
## Consequências
```

Um ADR aceito não é reescrito: uma mudança de rumo vira um novo ADR, que substitui o anterior.

Mudanças na interface da seção 5.10 também exigem avisar João e atualizar `docs/PLAN.md` na mesma alteração.
